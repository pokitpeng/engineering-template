# 业务验收测试

项目初始化后选择适合的测试框架。这里放跨模块或跨系统的验收测试；局部测试与源码放在一起。

测试名称或注释引用规格中的规则 ID。覆盖关键正常路径、权限、失败、重试、并发和恢复场景。人工验收也应记录负责人及证据。

验收方案、人工验收记录和证据索引统一放在 [docs/acceptance](../../docs/acceptance/README.md)，可观测性场景见 [验收清单](../../docs/acceptance/observability.md)。本目录保留给实际测试代码，不将文档检查当作业务测试。

本目录目前只有说明，没有业务测试。不得将模板 CI 通过描述为业务验收完成。
