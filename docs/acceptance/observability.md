# 可观测性验收清单

依据 [OBS 基线](../specs/observability.md)，由 AI 在技术栈选定后实现适用测试。此文件是验收设计，不是测试程序或通过证据；模板没有运行中的服务、SDK 或采集后端。

可执行验收测试放在仓库的 `tests/acceptance/` 或项目选定的测试目录，本目录只保存验收方案和证据索引。

## 项目验收入口

- 本地/CI 启动和清理测试采集环境：{{OBS_TEST_ENV_COMMAND}}
- 执行自动化验收：{{OBS_ACCEPTANCE_COMMAND}}
- 测试代码与 CI job 位置：{{OBS_TEST_CODE_AND_CI_JOB}}
- 部署侧验收负责人及记录：{{OBS_DEPLOYMENT_VERIFICATION}}

使用合成数据、固定测试版本和隔离命名空间，不对生产注入故障。测试断言需等待有界的导出/抓取周期，不能用不确定的固定睡眠冒充验证。

## 最低验收矩阵

| 场景 | 规则 | 必须断言 | 初始状态 |
| --- | --- | --- | --- |
| 正常请求/任务 | OBS-001/002/003/004 | 身份一致；操作结果日志可查询；计数和延迟正确；采样开启的测试中日志 trace/span 与实际链路一致 | 未执行 |
| 业务拒绝与系统失败 | OBS-002/003/004 | 结果分类不同；不泄露异常秘密；span/错误指标遵守语义；同一故障不重复输出堆栈 | 未执行 |
| 依赖超时与重试 | OBS-003/004 | 每次尝试与最终结果可区分；逻辑计数不重复；超时位置和耗时可定位 | 未执行 |
| 并发与异步/队列 | OBS-004 | 不同请求上下文不串线；消息跨边界 parent/link 符合设计；无效入站上下文安全处理 | 未执行 |
| 注入合成秘密及日志控制字符 | OBS-005 | 检查原始导出数据：所有三类信号无秘密/载荷泄露，日志结构未被篡改 | 未执行 |
| 高基数输入 | OBS-003/006 | 变化的用户/请求 ID、URL 不产生无界指标标签或动态 span 名；实测序列数在预算内 | 未执行 |
| 采样降低/关闭 trace 导出 | OBS-003/006 | 请求/失败计数仍准确；界面/排障步骤承认 trace 可能缺失 | 未执行 |
| 采集器不可达、变慢或队列满 | OBS-006/007 | 业务结果正确；额外延迟、内存和队列有界；丢弃/失败可见，带外检查能发现全链路故障 | 未执行 |
| 启停与配置 | OBS-001/007 | 配置错误策略明确；停止时限时 flush，不无限等待；采集端点有访问保护 | 未执行 |
| 告警触发、无数据与恢复 | OBS-008 | 查询可执行；告警到达指定测试接收者；触发/恢复和无数据行为符合设计，runbook 可用 | 未执行 |
| 客户端/离线工具 | OBS-009 | 故障仍可定位；离线/不同意采集不阻塞业务；无密钥或非授权第三方上下文泄露 | 未执行 |
| 性能开销比较 | OBS-006 | 在固定负载/环境下比较采集开关和故障场景，延迟/CPU/内存/存储量符合预算 | 未执行 |

不适用项需链接架构中的裁剪批准，不可直接标记通过。部署侧告警/权限验收不一定适合普通 CI，但应成为实际发布门禁。

## 证据记录

每次验收记录：提交版本、环境、运行时间、执行人/代理、命令、期望断言、实际结果、脱敏查询样本/报告位置、未验证项和清理结果。

自动化结果使用项目 CI 报告作为权威来源，本表可以链接报告而不复制测试日志。只有文档结构检查通过时，所有运行时场景仍视为未验证。
